# Home Cybersecurity Lab

## Objective

Build a home cybersecurity environment to practice:

- Network Enumeration
- Web Server Administration
- Blue Team Defense
- Red Team Reconnaissance
- Remote Administration
- VPN Networking

---

## Hardware

- HP Desktop
- Raspberry Pi 5
- Raspberry Pi Mini Keyboard

---

## Software

- Windows
- VirtualBox
- Ubuntu Server
- Kali Linux
- Apache2
- Tailscale
- GitHub
